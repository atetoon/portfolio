# Dhruv Pandey — Portfolio

A minimal, editorial-style personal website built with Next.js App Router.

## Getting started

Requires Node.js 20.9 or newer.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Add your banner GIF

Put your own GIF at:

```text
public/images/banner.gif
```

The homepage already references `/images/banner.gif`.

## Pages

- `/` — Home
- `/blog` — Blog

## Build for production

```bash
npm run build
npm start
```

This is a fresh project and is intentionally separate from the previous HTML/CSS portfolio.
